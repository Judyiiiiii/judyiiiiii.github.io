# Xuewen Wang — Portfolio

Personal portfolio of Xuewen Wang, an Electronic and Electrical Engineering student at City University of Hong Kong.

Website: https://judyiiiiii.github.io/

The site uses plain HTML, CSS and JavaScript. GitHub Pages publishes the repository root from the `main` branch; `.nojekyll` keeps the files unchanged. No installation, API keys or build step is required.

Edit `app.js` for bilingual experience and project descriptions; `index.html` for page structure and links; `motion.css`, `motion.js`, `workbench.css` and `workbench.js` for visual styling and animation. Résumé PDFs and artwork are in `assets/`, along with bundled font licenses and illustration provenance.
